# flutter_watchkit example

Demonstrates the `flutter_watchkit` plugin: session status, applicationContext
push, and watch-originated commands.

## Run the iOS app

```sh
flutter pub get
flutter run        # or: flutter build ios --no-codesign
```

The plugin is wired automatically via the generated plugin registrant — no
manual Swift setup is needed on the iOS side.

## Add the watchOS companion app

Xcode targets cannot be generated by `flutter create`, so the watch target is
a one-time manual step:

1. Open `ios/Runner.xcworkspace` in Xcode.
2. **File → New → Target… → watchOS → Watch App** (SwiftUI, watchOS 10+),
   e.g. name it `WatchKitDemo Watch App`.
3. Delete the template sources Xcode generated for that target, then add the
   reference sources from `example/watch_app/` to the watch target:
   `WatchKitDemoApp.swift`, `WatchSessionStore.swift`, `ContentView.swift`,
   `Assets.xcassets`, and `Info.plist`.
4. Set the watch target's bundle id to
   `<runner bundle id>.watchkitapp` and make sure its
   `WKCompanionAppBundleIdentifier` equals the Runner bundle id.
5. Select the watch scheme and run on a Watch simulator paired with the
   iPhone simulator running this example.

The watch demo activates `WCSession`, renders the latest applicationContext,
and sends a `ping` command (`sendMessage` with `transferUserInfo` fallback)
that appears in the example app's "Last watch command" card.
